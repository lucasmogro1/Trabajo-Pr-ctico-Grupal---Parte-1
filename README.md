## 📌 Descripción del Proyecto
Este repositorio contiene el desarrollo incremental de un sitio web informativo y de promoción turística para una ciudad completamente ficticia. El proyecto evolucionará incorporando progresivamente HTML semántico, estilos CSS, diseño responsivo con Bootstrap y funcionalidades con JavaScript.

## 🗂️ Estructura del Sitio (Etapa 1)

El sitio web está compuesto por las siguientes páginas base distribuidas entre el equipo:
* 🏠 **`index.html`** - Inicio y presentación general de la ciudad.
* 📜 **`ciudad.html`** - Historia, identidad, costumbres y datos clave.
* 📍 **`lugares.html`** - Atractivos turísticos, actividades y propuestas.
* 📞 **`contacto.html`** - Oficina de turismo, enlaces telefónicos/mail y redes.

## 🛠️ Buenas Prácticas de Git (Requeridas por la Cátedra)

Para mantener un historial limpio, utilizaremos prefijos estandarizados en nuestros mensajes de commit:
* `feat:` Para agregar nuevas secciones o funcionalidades (Ej: `feat: agrego sección de contacto`)
* `style:` Para cambios estéticos o de diseño (Ej: `style: modifico colores del header`)
* `fix:` Para corregir errores en el código.
* `docs:` Para cambios en la documentación .
